# AssureX V1 Train-Ready Dataset

This folder is the canonical V1 naming layer for the active 14-feature AssureX model.

The CSV contents are copied from the currently active training, validation, test, feature, metrics, and prediction artifacts so that a V1 training run can reproduce the same behavior currently used by the application.

Runtime model metadata now reports:

- Python model: `Gradient Boosting V1 (14 Features)`
- Python version: `v1-final-14feat`
- GTM model: `Google Teachable Machine G2 V1`
- GTM version: `gtm-g2-v1-final`

The older physical artifact filenames are kept for compatibility with existing scripts and saved model paths.
